**Credits**: 3

**Prerequisites**: None

> This course introduces students to programming in C. The course covers fundamental programming constructs including variables, expressions, selection statements, loops, arrays, comments, functions, structures, pointers, strings, and dynamic memory allocation. The course emphasizes structured programming and top-down design. Additional topics include recursion, debugging, and an introduction to basic data structures and algorithms. Introduction to industry practices for team programming.
