**Prerequisites**: [CS 101](/academics/courses/engineering/cs101) (Coreq),
[CS 160](/academics/courses/engineering/cs160) (Coreq),
[ECE 261](/academics/courses/engineering/ece261) (Coreq)

> This course focuses on one particular complex software system to introduce a wide range of computer science principles. In a computer laboratory setting, students investigate design methodologies, including working collaboratively on large software systems. Testing, code re-use, versioning, meeting specifications and user requirements, and viewing a software system from low level systems considerations to the user interface. By the end of the semester, the class will have developed a complete functioning system.
