**Credits**: 3

**Prerequisites**: [CS 102](/academics/courses/engineering/cs102),
[CS160](/academics/courses/engineering/cs160)/[ECE 160](/academics/courses/engineering/ece160)

> This course will introduce students to the essential data structures and algorithms that are routinely used by software engineers and researchers. Data structures and algorithms covered in the course will include lists, stacks, queues, trees, hash tables, priority queues, and sorting algorithms. Students will learn about Big-O and related notations for evaluating the efficiency of algorithms and data structures. The course will also provide an overview of C++, including coverage of important object-oriented concepts and generic programming using templates.
