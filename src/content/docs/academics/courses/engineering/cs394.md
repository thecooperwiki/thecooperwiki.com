**Credits**: 3

**Prerequisites**: [CS 361](/academics/courses/engineering/cs361),
[CS 366](/academics/courses/engineering/cs366)

> This course will allow Juniors to apply what they have learned in previous courses, such as Software Engineering, and also teach new material related to modern software engineering practices. Topics will include techniques related to advanced object-oriented programming and agile programming. In small groups, students will implement systems using a modern, object-oriented programming language such as Java, making iterative improvements, and will refactor existing code to add features or make other improvements. Emphasis will be placed on code reviews, in-code documentation, creating test suites, and following agile practices. Some lectures will involve in-person discussions of code, including code reviews.
