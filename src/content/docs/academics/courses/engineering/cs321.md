**Credits**: 3

**Prerequisites**: [CS 261](/academics/courses/engineering/cs261),
[ECE 251](/academics/courses/engineering/ece251)

> Parallel programming and distributed algorithms. Threaded applications, GPU parallel processing. Cloud computing: large distributed systems, fault tolerance; storing, retrieving and processing distributed data; functional programming (MapReduce); Hadoop. Security in distributed systems. Students work on projects using a variety of tools for a range of target systems and applications, from a rack of GPU cards to datacenter scale server systems.
